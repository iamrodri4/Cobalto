Ilustración de la interfaz

Lo que necesitas para programar

Cobalto usa Monaco, el mismo motor de texto de código abierto que hay dentro de otros editores conocidos, con colores y una interfaz propios.

▶

Ejecuta con F5

Python y JavaScript corren directo desde el editor. Si tu programa pide algo con input(), lo respondes ahí mismo. Las páginas HTML se abren en tu navegador.

>_

Terminal incluida

Una terminal simple abajo, que parte en tu carpeta, para comandos como pip install o git status.

⌕

Búsqueda en la carpeta

Encuentra una palabra en todos los archivos de tu proyecto y salta directo a la línea con un clic.

◐

Cuatro temas

Cobalto, Medianoche, Grafito y Claro. Cambias con un clic y se recuerda para la próxima vez.

↺

Vuelve donde lo dejaste

Al abrir, recupera tu carpeta y los archivos que tenías abiertos. Con el autoguardado, tampoco pierdes cambios.

◇

Liviano y sin cuenta

No necesitas registrarte ni iniciar sesión. Lo instalas y lo abres.

¿Es seguro? Compruébalo tú mismo

Cobalto es un programa nuevo, así que no te pedimos que confíes a ciegas. Estas son las formas de revisarlo antes de instalar.

  • Código abierto.
    Todo el código está en GitHub. Cualquiera puede leerlo y ver qué hace.
  • Sin recopilar datos.
    El editor no envía tus archivos ni tu información a internet. (Los programas que tú ejecutes sí pueden usar internet, como cualquier programa.)
  • Sin cuentas ni anuncios.
    No hay registro, publicidad ni versiones de pago.

Verifica tu descarga

Análisis antivirusSe agrega al publicar la versión.
Huella SHA-256Se agrega al publicar la versión.

Para comprobar la huella de tu archivo, abre una terminal en la carpeta de descargas y escribe:
certutil -hashfile Cobalto-Setup-0.2.0.exe SHA256
Si el resultado es igual al de arriba, el archivo es el original.

Una nota honesta: los programas nuevos a veces son marcados por error por algún antivirus (un “falso positivo”). Por eso publicamos el análisis completo, para que veas el detalle y decidas con información.

Cómo instalar

Te lleva menos de un minuto.

  1. Descarga el instalador.

    Usa el botón de arriba. Es un archivo que se llama Cobalto-Setup-0.2.0.exe.

  2. Ábrelo.

    Si Windows muestra “Windows protegió tu PC”, mira la primera pregunta de más abajo: explica por qué pasa y qué hacer.

  3. Elige la carpeta y termina.

    Se crea un acceso directo en tu escritorio y en el menú Inicio.

  4. Para ejecutar Python,

    necesitas tener Python instalado (python.org, marcando “Add Python to PATH”). JavaScript funciona sin instalar nada más.

Preguntas frecuentes

Lo que más se pregunta antes de instalar.

Windows dice “Windows protegió tu PC”. ¿Qué hago?

Ese aviso (SmartScreen) aparece con programas nuevos o sin firma digital, y Cobalto todavía no la tiene. Si descargaste el instalador desde el repositorio oficial de Cobalto y la huella SHA-256 coincide con la de esta página, puedes continuar: toca “Más información” y luego “Ejecutar de todas formas”. Si algo no coincide, no lo ejecutes.

¿Funciona en Mac, Linux o celular?

Por ahora el instalador es solo para Windows 10 y 11.

¿Por qué mi antivirus lo marcó?

Los programas nuevos, que casi nadie ha descargado todavía, a veces son marcados por precaución aunque no tengan nada malo. Revisa el análisis publicado y la huella del archivo. Si crees que es un error del antivirus, puedes enviarles el archivo para que lo revisen.

No. Cobalto es un proyecto independiente. Usa Monaco Editor, un componente de código abierto con licencia MIT, y no tiene relación con Microsoft ni con Visual Studio Code.
